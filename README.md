# 🏁 Featured Work:
**NASCAR Archive Modernization** (via Envorso)
- Built an end to end pipeline: TwelveLabs Pegasus (AWS Bedrock) generates tags, output is transformed into JSON-LD and ingested into Perfect Memory through the Wisdom API so tags render in NASCAR's CAM system
- Automated QC pass (`qc_auto.py`) adopted by NASCAR as the QC benchmark, plus a quality gate (`qc_gate.py`) that blocks publishing on known faults
- Race phase derivation from NASCAR livelog data, entry list registry checks, sponsor alias handling, and segment boundary tightening
- Nashville race backfill: 1,500 tags, 371 comments, and 31 phase spans across 8 clips with all quality gates passing
- One command CLI automation, scaled toward ~5 races per day

**KencoGPT** (Kenco Group): LangChain + GPT-4 + FAISS document query system with a 77% cut in retrieval cost

**Workforce AI** (Kenco Group): XGBoost and Random Forest ensemble forecasting labor across 500K+ daily records for Fortune 500 clients
